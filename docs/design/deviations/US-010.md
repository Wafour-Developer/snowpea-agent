# Deviations — US-010 (execution backends: local / docker / ssh)

Against `docs/design/m2-tools-contract.md` §1. Recorded here rather than appended to the contract, per the lead's note about concurrent edits losing sections.

1. **`ExecResult`, not `RunResult`.** M1 already shipped `exec/backend.py::ExecResult` with exactly the contract's fields (`exit_code, stdout, stderr, timed_out`) and `tools/shell.py` reads it. `RunResult` is exported as an alias so contract §1 spelling resolves; no call site changed.
2. **`read_file`/`write_file` carry `str`, not `bytes`.** Same reason: US-005's `tools/fs.py` already passes text through `ctx.backend`, and switching to bytes would have broken every file tool mid-M2. SFTP and `docker exec` encode/decode UTF-8 with `errors="replace"` at the boundary.
3. **`cwd` is a read-only property returning `PurePath`, not `def cwd() -> str`.** M1 shipped it as a property and `LocalBackend` returns a real `Path`; the remote backends return `PurePosixPath`. `PurePath` is the common supertype, so the protocol stays satisfiable by all three. `resolve(path)` is part of the protocol for the same reason.
4. **`run` gained an `env` keyword** (contract §1 lists it; M1's `LocalBackend` did not have it). Additive, defaults to `None`.
5. **The `backend.changed` payload field is `backend`, not `kind`.** `kind` is the session-event discriminator in `SESSION_EVENT_MODELS`, so the payload would have collided with it. Event: `{"kind": "backend.changed", "payload": {"backend": "docker"}}`.
6. **The handler lives in `server/session_handlers.py`, not `server/app_server.py`.** Every other session-scoped handler moved there in US-005 and `app_server.build_dispatcher` only wires `system.*`; putting `backend.set` beside its peers keeps the session lookup helper (`_session`) and the `HANDLED_METHODS` list in one place. `backend.set` was also added to `IMPLEMENTED_METHODS`.
7. **`/backend` registers through `commands/registry.py`, not `commands/builtin.py`.** `register_builtin_commands` now composes `builtin.COMMANDS + mode_cmd.COMMANDS + backend_cmd.COMMANDS`; `builtin.py` is owned by the permissions story, so the command list was extended at the composition point instead.
8. **`exec/factory.py` is new.** `build_backend(kind, config, workdir=, session_id=)` is the single place that turns wire params into a backend, shared by the RPC handler and the slash command so they cannot drift.
9. **Docker container reuse.** If a container with the session's name already exists and is running, it is reused rather than recreated; a stopped one is removed first. `close()` always does `docker rm -f`.
10. **SSH host-key verification is off by default** (`known_hosts=None`), which is what the throwaway fixture needs. Pass `knownHosts` in the backend config to verify a real host. Documented in `exec/ssh.py` and `tests/fixtures/ssh/README.md`.
11. **`Session.backend` is typed non-optional and filled in `__post_init__`** with `LocalBackend(workdir)`, so no caller has to null-check it. `SessionManager.close` now awaits `backend.close()` and swallows failures so a dead container cannot block session teardown.
