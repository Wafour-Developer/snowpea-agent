# US-011 deviations — M3 providers ×11, normalization, replay, web login

Recorded against `docs/design/m3-providers-setup-contract.md` §1–§4 (that
document stays the contract; this file records where the implementation differs).

## Deviations

Implemented: `providers/presets.py`, `normalize.py`, `openai_compat.py`,
`gemini_native.py`, `replay.py`, `auth_web.py`, `registry.py`,
`scripts/scrub_fixtures.py`, fixtures for all 11 vendors,
`tests/test_provider_matrix.py`. Setup wizard (§5) is US-012's.

1. **`VendorPreset` keeps `models` and a `vendor` property.** §1 names the field
   `id`; the M1 code and `provider.list` already spoke `vendor`, so `id` is the
   field and `vendor` is a read-only alias. `models: tuple[str, ...]` survives
   from M1 because `provider.list` returns it.
2. **`PRESETS` is a `dict[str, VendorPreset]`** as §1 says (it was a tuple at
   M1); `PRESETS_BY_VENDOR` is kept as an alias. The `local` sub-presets live in
   `LOCAL_VARIANTS` (`vllm` / `ollama` / `lmstudio`), selected with
   `settings.providers.local.variant`; they share the id `local`.
3. **`ProviderInfo` gained `label` and `defaultModel`** (additive; protocol
   regenerated). §1 asks `provider.list` for both.
4. **Fixtures carry a `wire` field** (`openai` | `anthropic` | `gemini`) next to
   the keys §4 lists, so `replay.py` can re-serialise chunks to SSE without
   consulting the presets. `response_stream` holds *decoded* chunks rather than
   raw bytes so the files stay reviewable; `synthetic: true` everywhere, and a
   `note` records that no real key was used.
5. **Replay swaps the transport, not the client.** `SNOWPEA_PROVIDER_MODE=replay`
   plus `providers.replay.replaying(vendor)` installs an `httpx` transport that
   answers in request order. The Anthropic SDK ships its own `httpx2`, so
   `replay.transport_for()` takes the http module and the transport class is
   built per module.
6. **`usage` is always emitted, including on the final turn.** §4 writes the
   second exchange as `text_delta* → done(end_turn)`; every adapter (M1's
   Anthropic one included) emits `usage` immediately before `done`, so the
   matrix test asserts `text_delta* → usage → done(end_turn)`.
7. **OpenAI device-code endpoints are placeholders.** No public, stable device
   authorization endpoint is documented for OpenAI, so `auth_web.ENDPOINTS`
   carries `auth.openai.com/oauth/device/code` + `/oauth/token` and the client id
   `snowpea-cli`. §3 anticipated this: correcting them is a data edit.
8. **CLI verb is `snowpea provider login <vendor>`** (plus `snowpea provider
   list`), added additively; `snowpea setup --login <vendor>` is US-012's alias.
9. **`supports_parallel_tools=False` for `deepseek` and `local`**, which makes
   `normalize` emit only the first tool call of a turn for them.
10. **Fake provider gained `delaySec`** on a step, and
    `tests/fixtures/providers/fake/scripted.py` re-exports `FakeProvider` (one
    implementation). `tests/fixtures/providers/fake/basic.json` gained a
    `stall forever` step, which un-skips `test_timeout_exits_five`.
