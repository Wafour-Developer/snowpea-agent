# 외부 세션 (베타)

외부 세션은 이 컴퓨터에서 도는 다른 에이전트 CLI의 세션입니다. Claude Code, Codex, Antigravity(agy), Cursor agent가 여기에 해당합니다. snowpea는 세션을 작업 폴더별로 묶어 보여 줍니다. 데스크톱 앱, 웹, 터미널 UI에서 외부 세션을 snowpea 터미널로 열어 그대로 이어 갈 수 있습니다. 자비스는 [자비스 모드](jarvis.md)의 규칙에 따라 외부 세션을 읽고 지시할 수 있습니다. [원격 머신](machines.md)의 외부 세션도 같은 방식으로 다룹니다.

이 기능은 베타입니다. CLI의 세션 기록은 공개된 형식이 아니므로, CLI 버전이 바뀌면 기록도 바뀔 수 있습니다.

다른 언어: [English](../en/external-sessions.md) · [전체 목록](../README.md)

관련 문서: [자비스 모드 (베타)](jarvis.md) · [보안 목록](security.md) · [에이전트와 위임](agents.md) · [터미널 UI](tui.md)

## 외부 세션이란

- snowpea는 데몬이 도는 컴퓨터에서 CLI 네 가지를 찾습니다. 설치되지 않은 CLI는 "설치 안 됨"으로 나옵니다. 설정에서 CLI마다 끌 수 있습니다.
- 세션은 프로젝트별로, snowpea 세션과 같은 목록에 나옵니다.
- 세션은 항상 snowpea 터미널 패널에서 열립니다. CLI 자체가 그 패널에서 돌고, snowpea는 상태를 점으로 보여 줍니다. 승인과 질문은 그 패널의 CLI가 처리하며, snowpea가 볼 수 있는 범위에서 [snowpea의 승인 규칙](#승인)이 적용됩니다.

## 세션의 세 가지 종류

외부 세션마다 **실행 위치**(호스트)가 있습니다. 프로세스가 어디서 돌고 있는지에 따라 할 수 있는 일이 정해집니다.

| 실행 위치 | 뜻 | 할 수 있는 일 |
|---|---|---|
| **snowpea가 실행** | snowpea가 이 세션의 프로세스를 실행하고 승인을 처리합니다 | 메시지 보내기, 중지, 모드 변경, 세션 종료. 승인이 snowpea에 나타납니다. |
| **다른 터미널에서 사용 중** | CLI가 snowpea 밖에서 돌거나, 재개 충돌 뒤 snowpea가 그 프로세스를 따라 봅니다. | snowpea는 그 프로세스가 끝날 때까지 읽기 전용으로 따라갑니다. 자세한 내용은 [snowpea 터미널에서 이어 가기](#snowpea-터미널에서-이어-가기)를 보세요. |
| **실행 중 아님** | 프로세스가 없습니다. snowpea는 기록만 보여 줍니다. | 기록을 읽습니다. 열면 snowpea 터미널에서 재개되며, 거기서 보내는 메시지가 대화를 이어 갑니다. |

## 만들기, 불러오기, 보내기, 중지

데스크톱 앱과 snowpea 웹의 사이드바에서 프로젝트는 세션을 한 목록으로 보여 줍니다. snowpea 세션과 외부 세션이 함께 나오고, 줄마다 그 세션을 돌리는 에이전트의 아이콘이 붙습니다. 프로젝트의 **+** 메뉴에는 **새 세션**과 **새 외부 세션…**이 있습니다. 뒤의 것을 열면 대화상자가 나오는데, 맨 위에 **새 세션 시작**(Start new session)이 있고 그 아래에 프로젝트의 세션이 최신순으로 나옵니다. 세션을 고르면 터미널에서 재개합니다.

| 하는 일 | 앱에서 | 터미널 UI에서 |
|---|---|---|
| 새 세션 시작 | 프로젝트 **+** → **새 외부 세션…** → **새 세션 시작**, 그다음 권한 옵션을 고릅니다 | `/external new` |
| 이 폴더의 세션 열기 | 프로젝트 **+** → **새 외부 세션…**에서 그 줄을 고릅니다(에이전트 아이콘으로 어느 CLI인지 보입니다) | `/external`(선택 목록) |
| 이름(핸들)으로 세션 열기 | 프로젝트의 세션 목록에서 고릅니다 | `/external open <cli>:<id>`. `<cli>`는 `claude`, `codex`, `agy`, `cursor` 중 하나입니다 |
| 메시지 보내기 | 입력창에 쓰고 보냅니다 | 프롬프트에 입력합니다 |
| 진행 중인 턴 중지 | **중지** | **Esc** |
| 화면을 떠나고 세션은 계속 돌리기 | 탭이나 패널을 닫습니다 | `/external close` |
| 프로세스를 멈추고 기록은 남기기 | **세션 종료** | `/external stop` |
| 이전 메시지 더 불러오기 | **이전 메시지 불러오기** | `/external more` |

이 동작에 대한 참고입니다.

- **세션을 읽기만 해서는 아무것도 시작되지 않습니다.** 돌고 있지 않은 세션을 열어 보는 것은 읽기만 합니다. 처음 보내는 메시지가 세션을 이어 갑니다. 그때 모드를 고르지 않았다면 CLI의 기본 모드로 이어집니다.
- **떠나기와 종료는 다릅니다.** 화면을 떠나면 프로세스는 계속 돕니다. 종료하면 프로세스가 끝납니다. 두 경우 모두 기록은 남습니다.
- **터미널 UI의 Esc.** 열린 외부 세션에서 Esc는 진행 중인 턴을 멈춥니다. 도는 턴이 없으면 Esc는 세션 화면을 떠납니다(세션은 계속 돕니다). 다른 터미널에서 도는 세션은 snowpea가 중지할 수 없어서, Esc를 누르면 안내 메시지가 나오고 곧바로 Esc를 한 번 더 누르면 화면을 떠납니다.
- **턴이 도는 중에는 새 메시지를 받지 않습니다.** 입력창에 CLI가 아직 작업 중이라고 나옵니다. 턴이 끝나기를 기다리거나 **중지**를 누르세요.
- **진행 중인 턴에 덧붙이기(Codex만).** **진행 중인 턴에 덧붙이기**는 지금 돌고 있는 턴에 입력한 내용을 바로 넣습니다. 돌고 있는 턴에 글을 받아 주는 CLI는 Codex뿐입니다. Claude Code, agy, Cursor agent는 턴이 끝나기를 기다리거나 중지하세요.
- **다른 터미널에서 돌고 있는 세션**에는 snowpea가 입력할 수 없습니다. 그 터미널에서 멈추세요.

## 승인

CLI가 권한을 물으면 그 요청이 snowpea에 일반 승인으로 나타납니다. 허용하거나, 거부하거나, **이 세션에서 허용**을 고를 수 있습니다.

- **이 세션에서 허용**은 정확히 같은 호출 하나만 기억합니다. 같은 도구와 같은 명령 줄 전체, 또는 같은 인자들이 해당합니다. 자비스의 위험 항목 규칙이나 항상 사용자에게 가는 규칙에 걸리는 요청에는 적용되지 않습니다. 그런 요청은 항상 사용자에게 옵니다.
- **차단 명령.** [보안 목록](security.md)에 있는 명령은 묻기 전에 거부됩니다. snowpea가 처리하는 승인에 대해서는 이것이 적용됩니다. 제한 없음 세션이나 승인을 CLI 터미널에서만 받는 세션 안까지는 닿지 않습니다.
- **CLI 터미널에서 승인.** 세션이 snowpea 터미널 패널에서 돌 때 권한 질문은 그 패널에 남습니다. 자비스도 다른 CLI 터미널과 같은 규칙을 따릅니다([터미널 세션 (베타)](terminals.md)).
- **제한된 승인.** 모드에 따라 동작마다 묻는 절차가 없습니다. 편집은 자동으로 허용되고, 그 밖의 것은 막힙니다. 입력창에 이런 세션이라는 표시가 나옵니다.
- **agy**는 agy 자체 설정의 승인 방식을 따릅니다. agy가 묻지 않고 실행하도록 설정되어 있으면 agy는 한 번도 묻지 않을 수 있습니다. snowpea는 세션 하나에 대해서 이를 바꿀 수 없습니다.

## 모드

CLI마다 자기 모드가 있고, snowpea는 그 모드를 CLI가 부르는 이름 그대로 보여 줍니다. 세션을 시작할 때 고르거나, 앱의 모드 전환이나 터미널 UI의 `/external mode <모드>`로 바꿉니다. snowpea는 설치된 CLI에게 어떤 모드가 있는지 물어보므로, 설치된 버전에 없는 모드는 보이지 않습니다.

모드는 두 가지로 설명합니다. CLI가 멈추고 사용자에게 묻는지, 그리고 무엇을 쓸 수 있는지입니다.

| CLI | 모드 | 사용자에게 묻는가 | 쓰는 곳 | 고를 수 있는 사람 |
|---|---|---|---|---|
| Claude Code | **Manual** (`default`, 2.1.326 이전 이름은 Default) | 권한이 필요할 때마다 | 허용받은 뒤 프로젝트 | 누구나, 자비스 포함 |
| Claude Code | **Plan** (`plan`) | 권한이 필요할 때마다, 그리고 작업을 시작하기 전에 | 자기 계획 파일만 | 누구나 |
| Claude Code | **Accept edits** (`acceptEdits`) | 명령 전에 묻고, 편집은 그대로 진행 | 프로젝트 | 사용자만 |
| Claude Code | **Auto** (`auto`) | 가끔. 스스로 진행하다가 확실하지 않을 때 묻습니다 | 프로젝트 | 사용자만 |
| Claude Code | **Don't ask** (`dontAsk`) | 묻지 않음. 사용자의 Claude Code 규칙이 허용하지 않은 것은 거절됩니다 | 사용자 규칙이 허용하는 곳 | 사용자만 |
| Claude Code | **Bypass permissions** (`bypassPermissions`) | 묻지 않음 | 어디든 | 사용자만 |
| Codex | **Untrusted** (`untrusted`) | 안전하다고 알려지지 않은 일은 모두 묻습니다 | 프로젝트(샌드박스) | 누구나. snowpea의 Codex 기본 모드 |
| Codex | **Read Only** (`read-only`) | 묻지 않음 | 아무것도 쓰지 않음(읽기 전용 샌드박스) | 누구나 |
| Codex | **Default** (`default`) | 가끔. 언제 물을지 Codex가 정합니다 | 프로젝트(샌드박스) | 사용자만 |
| Codex | **Full Access** (`full-access`) | 묻지 않음 | 어디든, 네트워크 포함 | 사용자만 |
| agy | **Default** (`default`) | agy 자체 승인 설정을 따름 | 프로젝트 | 누구나 |
| agy | **Plan** (`plan`) | agy 설정을 따르고, 작업 전에 대화창에서 묻습니다 | 자기 계획만 | 누구나 |
| agy | **Accept edits** (`accept-edits`) | 명령 전에 묻고, 편집은 그대로 진행 | 프로젝트 | 사용자만 |
| agy | **Auto** (`auto`) | 가끔. 편집과 안전한 명령은 진행하고, 되돌릴 수 없는 일은 묻습니다 | 프로젝트 | 사용자만 |
| agy | **Skip permissions** (`dangerously-skip-permissions`) | 묻지 않음 | 어디든 | 사용자만 |
| Cursor agent | **Ask** (`ask`) | 묻지 않음 | 아무것도 쓰지 않음. **Cursor의 시작 모드입니다.** | 누구나 |
| Cursor agent | **Plan** (`plan`) | 묻지 않음 | 자기 계획만 | 누구나 |
| Cursor agent | **Agent** (`agent`) | 묻지 않음. Cursor에는 여기로 가져올 질문이 없습니다 | 프로젝트(샌드박스) | 누구나 |
| Cursor agent | **Run Everything** (`yolo`) | 묻지 않음 | 어디든 | 사용자만 |

알아 둘 점입니다.

- **Plan 모드는 읽기 전용이 아닙니다.** 계획을 파일로 씁니다. Claude Code는 계획을 마치면 작업을 시작해도 되는지 묻습니다. 이 질문은 승인으로 사용자에게 오고, 사용자만 답할 수 있습니다. 자비스나 자동 규칙은 답하지 못합니다. 허용하면 세션은 기본 모드로 이어지고, 기본 모드는 바꾸기 전마다 묻습니다. 거절하면 Claude Code는 계속 계획을 다듬습니다. agy는 같은 질문을 대화창에서 합니다.
- **Auto도 가끔은 묻습니다.** Claude Code와 agy의 Auto 모드에서는 CLI가 대부분을 스스로 정합니다. 그래도 묻는 것은 기본 모드처럼 snowpea의 일반 승인으로 옵니다.
- **"읽기 전용"이라는 말은** 아무것도 쓰지 않는 모드에만 씁니다. Codex의 Read Only와 Cursor의 Ask입니다.
- **"사용자만"으로 표시된 모드는** 아래 제한 없음 모드와 같은 확인을 거칩니다. 앱, 웹 앱, 터미널 UI 앞의 사람만 고를 수 있고, 원격 웹 로그인으로는 고를 수 없으며, 고를 때마다 자비스 원장에 기록됩니다. 자비스는 이런 모드를 고르지 못하고, 이런 모드로 도는 세션에 일을 보내지도 않습니다. 나중에 이어 가는 세션은 그 모드가 아니라 CLI의 기본 모드로 돌아옵니다.
- **예전 클라이언트는** 여전히 기본, 읽기 전용, 제한 없음의 세 모드만 봅니다. CLI의 모드는 각각 이 셋 중 하나로 보입니다. 예를 들어 Claude Code의 Plan은 읽기 전용으로, Auto는 기본으로 보입니다.

**제한 없음**(Bypass permissions, Full Access, Skip permissions, Run Everything)이 뜻하는 것입니다.

- CLI가 묻지 않고 실행합니다. snowpea가 무엇을 하는지 통제하지 못하므로, 자비스는 그 세션의 승인을 결정하지 않고, 위험 항목 규칙과 보안 목록도 그 안에는 적용되지 않습니다.
- **사용자만 고를 수 있고, 세션 하나에만 적용됩니다.** 선택은 기억되지 않습니다. 기본값이 될 수 없고, 이어 가는 세션은 제한 없음 상태로 돌아오지 않습니다. snowpea는 CLI 이름, 이 모드가 허용하는 것, 폴더를 적은 확인 창을 띄우고, 모드를 바꿀 때마다 자비스 원장에 기록합니다.
- 원격 웹 로그인으로도 고를 수 없습니다. [다른 컴퓨터에서 자비스 쓰기](jarvis.md#다른-컴퓨터에서-자비스-쓰기)를 보세요.
- 자비스는 제한 없음 세션을 시작할 수 없습니다. 메신저에서는 본인이 직접 시작한 턴에서 한 번 눌러 허용할 수 있습니다. [자비스 모드의 메신저 항목](jarvis.md#메신저)을 보세요.

세션의 모드를 높이는 일은 언제나 사용자의 몫입니다. 자비스는 누구나 고를 수 있는 모드(예: Claude Code의 Plan)로 세션을 시작할 수 있지만, 그 뒤에 세션의 모드를 바꿀 수는 없습니다.

**터미널 세션 (베타).** 외부 세션은 항상 실제 터미널 패널에서 열립니다. CLI가 그 패널에서 돌고, snowpea는 상태를 점으로 보여 줍니다. 보기 방식, 권한 옵션, 자비스가 이 터미널을 다루는 방식은 [터미널 세션 (베타)](terminals.md)에, 세션 상태를 알려 주는 훅은 [CLI 훅 연동 (베타)](integrations.md)에 있습니다.

## snowpea 터미널에서 이어 가기

외부 세션을 열거나 이어 가면, 모든 CLI와 모든 OS에서 CLI가 snowpea 터미널 패널에서 그 CLI 자체의 재개 명령으로 시작됩니다. 세션 id는 [훅 연동](integrations.md)에서 옵니다(재개가 되지 않으면 먼저 `snowpea integration install`을 실행하세요).

- **snowpea는 항상 자기 패널에서 재개합니다.** 사용자가 연 터미널에 붙거나, 그 프로세스에 대신 입력하지 않습니다. 재개는 데몬이 잡는 패널에서만 이루어집니다.
- **다른 곳에서 이미 실행 중.** 같은 세션이 다른 터미널에서 살아 있으면 snowpea도 패널을 열고 재개 명령을 실행합니다. 두 프로세스를 허용할지는 CLI가 결정합니다. 거절하면(예: Codex의 "active writer", Claude Code의 살아 있는 세션) snowpea는 그 프로세스를 보기만 따라가고 경쟁 CLI를 시작하지 않습니다. 그 세션을 다른 터미널에서 끝낸 뒤 snowpea에서 다시 여세요.

권한 옵션, 상태 점, 자비스 규칙은 [터미널 세션 (베타)](terminals.md)를 보세요.

## 프로젝트를 외부 CLI에 대해 신뢰하기

프로젝트에서 처음으로 외부 세션을 열면 snowpea가 그 프로젝트를 신뢰할지 묻습니다.

이유: CLI는 프로젝트 자체의 설정과 훅을 읽습니다. 클론한 저장소가 여러분의 컴퓨터에서 코드를 실행하는 훅을 담고 있을 수 있습니다. 프로젝트를 신뢰한다는 것은 그 프로젝트 설정이 하는 일을 받아들인다는 뜻입니다.

- 신뢰는 사용자만 확인할 수 있습니다. 자비스, 브라우저 세션, 다른 프로그램은 확인할 수 없습니다.
- 신뢰 기록은 snowpea 홈 폴더의 `jarvis/external-trust.json`에 저장됩니다. 프로젝트 저장소에는 저장되지 않습니다.
- 프로젝트를 신뢰하기 전에는 그 프로젝트에서 외부 CLI를 시작하지 않습니다. 자비스가 시작하려 하면, 사람이 먼저 그 프로젝트에서 외부 세션을 열어야 한다는 답을 받습니다.

## 직접 지정한 CLI 경로

**설정 → 외부 에이전트 CLI**에서 CLI의 경로를 직접 지정하면, 확인하기 전까지 snowpea는 그 프로그램을 실행하지 않습니다. 버전 확인도 하지 않습니다. 확인 전까지 그 CLI는 경로가 대기 중으로 표시되고 설치된 것으로 치지 않습니다.

확인하려면 설정에서 확인 버튼을 누르거나, 터미널 UI에서 `/external confirm-path <cli>`를 입력합니다. snowpea는 확인 전에 실제 경로를 보여 줍니다. 경로 확인은 사용자만 할 수 있고, 원격 웹 로그인으로는 할 수 없습니다.

## CLI에 넘기는 환경 변수

CLI에는 안전한 변수만 짧은 목록으로 넘어갑니다. 검색 경로, 홈 폴더, 언어 설정, 터미널, 임시 폴더, 인증서와 프록시 설정, CLI가 자기 설정 폴더를 찾는 데 쓰는 변수입니다. 그 밖의 것은 제거됩니다. snowpea 데몬 토큰도 제거됩니다.

CLI에 API 키 같은 제공자 키가 필요하면, 그 변수 이름을 `jarvis.external.clis.<id>.passEnv`에 적습니다.

```json
{
  "jarvis": {
    "external": {
      "clis": {
        "claude": { "passEnv": ["ANTHROPIC_API_KEY"] }
      }
    }
  }
}
```

`passEnv` 규칙입니다.

- 사용자만 설정할 수 있습니다. 데몬이 도는 컴퓨터에서 snowpea로 설정합니다. 자비스는 설정할 수 없습니다.
- `SNOWPEA_`로 시작하는 이름은 거부됩니다. snowpea 자신의 변수는 CLI에 넘어가지 않습니다.
- 이름은 올바른 환경 변수 이름이어야 합니다.

## 자비스가 외부 세션으로 할 수 있는 일

자비스는 위의 규칙과 같은 범위에서 움직입니다. 요약하면 다음과 같습니다.

| 자비스가 할 수 있는 일 | 자비스가 할 수 없는 일 |
|---|---|
| 외부 세션 목록을 보고 읽음(요약으로 최대 200건) | 자비스에게 숨긴 프로젝트의 외부 세션을 읽음 |
| snowpea가 통제하는, 멈추지 않은 세션에 지시를 보냄 | 멈춰 있는 세션, 제한 없음 세션, 사용자만 고르는 다른 모드의 세션에 지시를 보냄 |
| 진행 중인 턴을 중지함 | 제한 없음이나 사용자만 고르는 다른 모드로 세션을 시작함(사용자에게 부탁할 수는 있음) |
| 누구나 고를 수 있는 모드(예: Plan)로 세션을 시작함 | 세션의 모드를 바꿈 |
| 위임 규칙에 따라 자기에게 배정된 승인에 답함 | 외부 CLI 터미널에서만 답하는 승인을 결정함 |

사용자가 자비스가 관리하는 세션에 입력하면 자비스는 그 세션에서 멈춥니다. [직접 끼어들기](jarvis.md#직접-끼어들기)를 보세요.

## CLI별 참고 사항

- **Claude Code.** 기록은 Claude Code 자체의 프로젝트 기록에서 가져옵니다. 구조화된 전송으로 돌 때 승인은 snowpea로 스트리밍됩니다. 터미널 패널에서는 질문이 패널에 남습니다.
- **Codex.** Codex 세션은 모두 snowpea가 실행하는 `codex app-server` 프로세스 하나를 공유합니다. 터미널이 닫힌 뒤에도 Codex가 세션을 놓는 데 1분 가까이 걸립니다(측정값 57초). 그동안 그 세션을 다시 여는 작업이 잠시 기다릴 수 있습니다. 진행 중인 턴에 글을 덧붙일 수 있는 CLI는 Codex뿐입니다(**진행 중인 턴에 덧붙이기**).
- **agy.** 승인은 agy 자체의 설정을 따릅니다. 그 설정이 묻지 않고 실행이라면 agy는 한 번도 묻지 않을 수 있고, snowpea는 세션 하나에 대해 이를 바꿀 수 없습니다. 그때는 모든 모드가 묻지 않는 것으로 보입니다. agy에는 읽기 전용 모드가 없습니다. Plan 모드도 계획을 씁니다.
- **Cursor agent.** 승인 요청을 snowpea로 보내지 않습니다. 읽기 전용인 Ask 모드로 시작합니다. Agent 모드에서는 편집과 샌드박스 셸 명령이 묻지 않고 실행됩니다. Run Everything은 `--yolo`로 실행합니다. Cursor agent는 도움 프로세스를 남길 수 있습니다. snowpea는 종료할 때 이를 정리합니다.
- **Windows.** snowpea는 외부 CLI 프로세스를 콘솔 창 없이 시작하고, CLI를 멈출 때는 그 CLI의 프로세스 트리 전체를 함께 끝냅니다. 데몬이 비정상 종료한 뒤 남은 CLI 프로세스를 정리하려면 프로세스 시작 시각이 필요한데 Windows에서는 얻을 수 없어서, 그런 프로세스는 자동으로 정리되지 않습니다.

## 터미널 UI 명령

| 명령 | 하는 일 |
|---|---|
| `/external` | 이 폴더의 세션 선택 목록을 엽니다 |
| `/external new` | 현재 폴더에 새 세션을 시작합니다 |
| `/external open <cli>:<id>` | 핸들로 세션을 엽니다 |
| `/external close` | 열린 세션을 떠납니다. 세션은 계속 돕니다. |
| `/external stop` | 열린 세션의 프로세스를 멈춥니다. 기록은 남습니다. |
| `/external mode <모드>` | 열린 세션을 그 CLI의 모드 중 하나로 바꿉니다. 위 표의 id를 씁니다(예: `plan`, `auto`, `read-only`). `default`, `readonly`, `unrestricted`도 그대로 됩니다. 사용자만 고르는 모드는 그 이름을 입력해 확인합니다. |
| `/external more` | 열린 세션의 이전 메시지를 더 불러옵니다 |
| `/external confirm-path <cli>` | CLI에 지정한 경로를 확인합니다 |

`/external` 뒤에 띄어쓰기를 하면 터미널 UI가 이 하위 명령을 보여 줍니다.

## 설정 참고

모든 설정은 `settings.json`의 `jarvis.external` 아래에 있습니다.

| 설정 | 기본값 | 역할 |
|---|---|---|
| `jarvis.external.enabled` | `true` | 외부 세션을 허용합니다. |
| `jarvis.external.maxProcesses` | `4` | snowpea가 동시에 실행할 CLI 프로세스의 최대 수(1~32). |
| `jarvis.external.idleSec` | `900` | 쉬고 있는 CLI 프로세스를 멈추기 전까지 두는 시간(초, 최소 30). |
| `jarvis.external.clis.<id>.enabled` | `true` | 이 CLI를 씁니다. `<id>`는 `claude`, `codex`, `agy`, `cursor` 중 하나입니다. |
| `jarvis.external.clis.<id>.path` | `null` | 실행 파일 경로. `null`이면 `PATH`에서 찾습니다. 경로는 확인한 뒤에만 실행됩니다. |
| `jarvis.external.clis.<id>.defaultMode` | `null` | 새 세션이나 이어 가는 세션이 시작할 모드. `null`이면 CLI의 기본 모드입니다(Cursor agent는 읽기 전용). 제한 없음은 여기서 받지 않습니다. |
| `jarvis.external.clis.<id>.passEnv` | `[]` | CLI에 넘길 환경 변수 이름. 사용자만 바꿀 수 있습니다. |
